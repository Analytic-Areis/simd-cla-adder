## 2. Technical Evaluation Rubric for Part-I

Part-I of `Course_project.pdf` requires students to design, simulate (NGSPICE), layout (MAGIC), and optimize a **4-bit Carry Look Ahead (CLA) Adder**.

### Strict Inclusion Criteria (RELEVANT):
1. **Direct Architecture Match**: Primary focus is a 4-bit Carry Look-Ahead Adder or its modular sub-blocks (Propagate/Generate $P/G$ generation, Carry Look-Ahead logic network $c_{i+1} = g_i + p_i c_i$, Sum generation $S_i = p_i \oplus c_i$).
2. **Transistor-Level Silicon CMOS / Logic Style**: Implements or compares transistor-level circuit topologies permitted by the project specification (Static CMOS, Dynamic CMOS, Domino logic, MT-CMOS, Pass-Transistor Logic (PTL), Transmission Gate (TG), Gate Diffusion Input (GDI), Adiabatic/Energy Recovery, or CMOS Mirror Logic).
3. **Sizing, Delay & Power Analysis**: Provides transistor sizing, worst-case propagation delay ($t_{pd}$), dynamic/leakage power dissipation, or layout/SPICE simulation methodologies.

### Exclusion Criteria (IRRELEVANT):
- **Unrelated Technologies**: Memristors, Optical/BDD logic, Single-Electron Threshold Logic (SET), Quantum/Reversible gates.
- **Different Bit-Widths**: 8-bit, 32-bit, 64-bit, or 256-bit architectures without dedicated 4-bit transistor CLA analysis.
- **Different Arithmetic Blocks**: Multipliers (Vedic/DSP), Comparators, BCD Decimal adders, Modulo $2^n \pm 1$ adders, Incrementers/Decrementers.
- **High-Level / FPGA Only**: Pure RTL/LUT synthesis on Xilinx/Vivado with no transistor-level schematics, layout, or SPICE simulation.
- **System / Testing Focus**: Full-custom neural net PEs, edge detection chips, IDDQ testing, or general device physics.
