# VLSI Course Project: 4-Bit Carry Look-Ahead Adder Papers

This repository contains research papers extracted from IEEE Xplore for **Part-I: 4-bit Carry Look Ahead Adder** of the VLSI Design Course Project (IIIT Hyderabad, Monsoon 2026).

## Directory Structure

- `papers/`: Contains the **19 strictly relevant papers** focusing on 4-bit CLA architectures, CMOS/dynamic/PTL logic styles, sizing, and delay/power benchmarks.
- `papers/Literature_survey_report_Inderjit_Singh.pdf`: Reference literature survey on 4-Bit CLA using CMOS Mirror Logic.
- `papers/archive_irrelevant/`: Contains **45 non-relevant papers** (multipliers, higher bit-widths, FPGA-only, memristors, optical, etc.) safely archived.
- `papers/relevance_report.md`: Complete audit report detailing technical evaluation and classification justifications for all 64 papers.
- `papers/papers_list.csv`: Comprehensive spreadsheet catalog with relevance statuses and local file paths.
